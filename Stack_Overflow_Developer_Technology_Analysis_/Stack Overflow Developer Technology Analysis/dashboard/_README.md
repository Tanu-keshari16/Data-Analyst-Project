# Dashboard

The dashboard provides an interactive view of technology usage, future technology preferences, and respondent demographics.

## Current Technology Usage

The first section examines the technologies respondents reported using, covering:

- Programming languages
- Databases
- Platforms
- Web frameworks

JavaScript has the highest selection count among programming languages, followed by SQL and HTML/CSS. PostgreSQL leads the database category, while AWS is the most selected platform. The web-framework view highlights technologies such as React and Node.js.

## Future Technology Trends

The second section focuses on technologies respondents would like to use or explore next.

The analysis shows strong future interest in JavaScript, SQL, TypeScript, and HTML/CSS among programming languages. PostgreSQL leads future database interest, while AWS remains the leading platform choice.

The comparison between current usage and future preferences helps highlight technologies with continued demand as well as areas where developer interest may be growing.

## Demographics

The final section provides context about the survey population through:

- Age distribution
- Country distribution
- Educational background
- Education levels across age groups

This demographic view helps put the technology findings into context rather than treating the technology counts as representative of an undifferentiated population.

## Dashboard Preview

The dashboard is organized into three views:

1. Current Technology Usage
2. Future Technology Trends
3. Demographics


## Key Takeaways

- JavaScript has the highest current programming-language selection count.
- SQL remains one of the most widely selected technologies.
- PostgreSQL leads both current database usage and future database interest.
- AWS leads the platform categories in both current usage and future interest.
- React and Node.js are prominent in the web-framework analysis.
- The respondent population is concentrated in a relatively small number of age and education groups, while the country distribution is global.
